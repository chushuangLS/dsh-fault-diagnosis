# 账户系统设计与维护

本文按 v1.1.0 实现整理，更新日期为 2026-11-10。

## 账户与角色

登录和注册使用唯一用户名，密码长度为 6 至 128 个字符。注册时需要确认密码并填写对应角色的邀请码。

| 角色 | 权限 |
|---|---|
| 普通成员 member | 使用诊断、查看和上报报修、编辑记录及修改状态 |
| 管理员 admin | 成员权限，以及删除报修、教室设备管理、报表导出、设置与操作日志 |

密码采用独立随机盐与 PBKDF2-HMAC-SHA256 存储。服务端保存可撤销会话，默认有效期为 12 小时。退出登录与重置密码会使对应会话失效。写入接口校验 CSRF，服务端独立验证角色权限。

## 邀请码

首次访问初始化 `data/invites.json`，其中 `admin_code` 用于管理员注册，`member_code` 用于普通成员注册。邀请码由三组四位十六进制字符组成，同角色可重复使用。

在项目根目录运行以下命令查看邀请码。

```powershell
python src/account_admin.py show-invite admin
python src/account_admin.py show-invite member
```

用以下命令轮换邀请码，再运行查看命令取得新码。

```powershell
python src/account_admin.py rotate-invite admin
python src/account_admin.py rotate-invite member
```

账户文件初始化后通过维护命令管理。邀请码保存在数据目录，本机维护命令可读取。

## 密码重置与历史上报人

```powershell
python src/account_admin.py reset-password "用户名"
python src/account_admin.py migrate-reporters "用户名" R001 R002
```

密码由交互提示输入。补登记命令只填写指定记录中空缺的上报人，重复运行保留已填写内容，并生成维护审计记录。记录编号应来自本机实际确认的清单。

## 报修与审计日志

报修 CSV 增加上报人、最后修改人和删除标记。读取旧表头时自动补齐字段，迁移前生成 `.pre-accounts.bak`。软删除保留原始记录与上报人。

`data/audit_log.jsonl` 记录操作时间、操作者、动作、记录与教室以及变更信息。管理员日志页支持关键词、操作类型、起止日期和时间排序，筛选完整历史后分页。界面可显示状态变化及字段修改详情。

报修写入使用待提交文件衔接 CSV 与审计日志，启动或读取时恢复未完成的日志写入，按事件编号避免重复追加。

## 桌面版数据目录

默认使用 EXE 同目录的 `data/`，也可通过 `DSH_DATA_DIR` 指定。维护命令应指向运行程序使用的数据目录。

升级程序时将原 `data/` 迁移到新版，保留 `users.json`、`invites.json`、`auth_*.json`、审计日志、报修记录及教室课表等业务数据。数据目录中的实际账户、密码哈希、邀请码和会话文件由本机运维管理。

## 界面与验证

登录字段统一显示“用户名”。侧边栏提供日志、账户和退出图标，收起时仅显示图标，展开显示用户名与角色。管理员日志页沿用深色表面、边框及蓝色强调色。

测试覆盖匿名和成员权限、CSRF、注册校验、会话失效、密码重置、CSV 迁移、日志恢复和筛选排序分页。桌面窗口验收状态见迭代日志。
