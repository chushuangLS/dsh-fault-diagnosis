# 机房故障智能诊断助手

> 一个面向高校机房运维场景的 AI 故障排查工具。
> 输入设备故障现象，输出结构化的排查步骤与处理建议。

## 项目背景

本项目的需求来自真实的机房运维工作：日常需要管理 **23 间机房教室、约 1840 台计算机设备**，
以及一支 **50 人的学生运维团队**。在实际运维中，高频故障（无法开机、网络中断、
外设失灵等）反复出现，排查过程依赖个人经验，新人上手慢、处理标准不统一。

本项目希望把这类经验沉淀成可检索、可复用的诊断工具，降低对个人经验的依赖。

## 快速开始（10 分钟复现）

### 1. 环境要求

- **Python 3.10 或更高版本**（开发环境为 Python 3.15.0）
- 无需额外依赖，当前版本仅使用 Python 标准库

检查 Python 版本：

```bash
python --version
```

### 2. 获取代码

```bash
git clone git@github.com:liyishuo1/dsh-fault-diagnosis.git
cd dsh-fault-diagnosis
```

### 3. 运行

```bash
python src/main.py
```

### 4. 使用

程序启动后会提示输入故障现象，例如输入 `开机`：

```
==================================================
  机房故障智能诊断助手  v0.1.0
==================================================

已加载 2 条故障案例

请描述故障现象（输入 q 退出）：开机

找到 1 条相关案例：

==================================================
【PC-001】开机故障
现象：按开机键没有任何反应，指示灯不亮，风扇不转

可能原因：
  1. 电源线未插紧或插座无电
  2. 电源开关（机箱后）被关闭
  ...

排查步骤：
  1. 检查电源线两端是否插紧（主机端和插座端）
  2. 换一个插座测试，确认插座有电
  ...
==================================================
```

输入 `q` 退出程序。

## 故障知识库格式

知识库为 JSON 格式，每条案例包含以下字段：

| 字段 | 说明 |
|---|---|
| `id` | 案例编号，如 `PC-001` |
| `category` | 故障分类，如"开机故障" |
| `symptom` | 现象描述（用于关键词匹配） |
| `causes` | 可能原因列表 |
| `steps` | 排查步骤列表（按顺序执行） |
| `severity` | 严重程度 |
| `est_time` | 预计处理耗时 |

示例：

```json
{
  "id": "PC-001",
  "category": "开机故障",
  "symptom": "按开机键没有任何反应，指示灯不亮，风扇不转",
  "causes": ["电源线未插紧或插座无电", "电源开关被关闭"],
  "steps": [
    "检查电源线两端是否插紧",
    "换一个插座测试"
  ],
  "severity": "高",
  "est_time": "5-10 分钟"
}
```
